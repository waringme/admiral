# FAQ List

Expandable question/answer list for admiral.com landing pages — e.g. "Your
questions answered". Each question is a white bordered box with a blue "+"
toggle; the answer opens inside the box. The first 3 questions show by default
and a **Show more** button reveals the rest.

## Authoring (Universal Editor)

Add a **Faq List** block, then add **Faq List Item** entries:

| Field | Type | Notes |
|-------|------|-------|
| Question | text | The question shown in the box |
| Answer | rich text | Answer shown when the box is opened (lists and links allowed) |

Put the section heading and intro above the block as normal text. The
**Show more** button appears automatically when there are more than 3 items.

## Not this block

- Long full-width content panels ("Read more about…") → use **accordion**.
