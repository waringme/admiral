# Side Image

An image beside text — admiral.com's side-image sections, e.g. "What is black
box insurance?" (character on the left) and "Black box van insurance" (van on
the right with a Find out more button).

## Authoring (Universal Editor)

Add a **Side Image** block and fill in:

| Field | Type | Notes |
|-------|------|-------|
| Image | reference | The illustration/photo |
| Image Alt Text | text | Accessible description (leave empty for decorative images) |
| Text | rich text | Heading, paragraphs and an optional link (a link on its own line becomes an outlined button) |
| Image Side | select | **Left** (default) or **Right** |
| Image Alignment | select | **Bottom** (default) — image sits on the section's bottom edge; **Centre**; **Top** — a tall image is cropped at the bottom |

Section styles work with it: e.g. **white** for a white band, **sky** for the
bright-blue band (text and button turn white).

On mobile the text shows first and the image below it.

## Not this block

- Several image + text rows stacked → use **media-panels**.
- Full-width photo hero with CTA buttons → use **hero-cta**.
